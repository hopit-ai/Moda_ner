# text track — suite code and data land per the availability table in README.

Unlike the image tracks, this one is **self-contained**: the labels are ours, so the splits
ship here directly rather than being rebuilt from a third-party corpus. No external dataset
acquisition is needed to run it.

The labels are silver — rule-derived from public fashion catalogues, no LLM API involved.
That caps what the track can tell you, and it is stated on every result it produces.
